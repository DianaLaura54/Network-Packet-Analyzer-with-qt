This is a cross-platform network packet analyzer written in C++ that captures and analyzes network packets on both Windows and Linux/Unix systems. It allows you to capture raw packets and filter them based on different criteria like protocol, IP address, and port number , while providing detailed information about Ethernet, IP, TCP, UDP, and ICMP headers. To ensure reliability, the project integrates GMock to verify the parsing logic and GTest to validate that the packet table model correctly handles and displays network data.
